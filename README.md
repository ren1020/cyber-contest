# My Project — スターター

このリポジトリはシンプルな静的サイトのスターターです。

使い方:

- ローカルで確認するにはブラウザで `index.html` を開いてください。
- VS Code の拡張 `Live Server` を使うと自動リロードで便利です。

ファイル:

- [index.html](index.html) — メインの HTML
- [css/style.css](css/style.css) — 基本スタイル
- [js/main.js](js/main.js) — 最低限のスクリプト（ナビゲーション切替など）

次のステップの提案:

- ページコンテンツを作成する
- ビルドツールやパッケージ管理（npm、Vite など）を追加する
- テストや CI の設定
